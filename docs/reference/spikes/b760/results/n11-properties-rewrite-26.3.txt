  motd=User motd kept
(the file already had motd=A Minecraft Server), and level-type and server-port were edited in place.

After the server started, the file had been rewritten by the server:
  - the hand comment was gone; the header is the server's two comment lines (title and a timestamp);
  - one motd line remained: motd=User motd kept (the last duplicate wins);
  - level-type=msmtest\:void_world and server-port=25599 were kept;
  - keys are written sorted, ':' escaped as '\:'.
