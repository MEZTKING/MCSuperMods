# ADR 0106: Data kinds sweep 2 and the data-only flows

## Context

[ADR 0064](0064-data-kinds-sweep.md) D4 left out, as "not worth it now", `sulfur_cube_archetype`, `test_environment`, `test_instance`, `block_transformer`, the two context providers, `slot_source`, `block_sound_set`, shaders, post effects and waypoint styles; `wolf_sound_variant` waited for a vendored mcdoc that described it. The user's rule of 2026-11-14 makes each of these a gap if vanilla data or resource packs can carry it. At f6a8adc (fact H9 of [the plan](../PLAN-vanilla-parity-3.md#fact-table-h1-to-h16)):

- the 26.3 world data folders (`dev.worldDataFolders`) include `decorated_pot_pattern`, `block_transformer`, `test_environment`, `test_instance`, `sulfur_cube_archetype` and `wolf_sound_variant`, none with a kind; `decorated_pot_pattern` became data in 26.3 (the mcdoc says `since 26.3`);
- the vendored mcdoc now describes `wolf_sound_variant` for 26.1 to 26.4 (a `concrete` node over `SoundVariant`);
- `context_int_provider` and `context_float_provider` are data folders (the compost values of ADR 0060 D4 read `context_int_provider/compostable/*.json`);
- the resource side has schemas for `post_effect`, `shader` and `waypoint_style`; project assets copy only `textures`, `sounds`, `font` and `texts` (fact H10);
- `slot_source` has a schema but no folder or registry on either target, and `gpu_warnlist` and `regional_compliancies` are game-internal: not pack content.

The coverage audit's section 3 also lists data-only flows never built: armour trim pattern, banner pattern and glider ([ADR 0044](0044-gear-weapons-and-consumables.md) D8), and now the decorated pot pattern.

## Decision

- **D1 Generic data kinds** (ADR 0015's tier B, schema forms): `minecraft:decorated_pot_pattern`, `wolf_sound_variant`, `block_transformer`, `test_environment`, `test_instance`, `sulfur_cube_archetype`, `context_int_provider`, `context_float_provider`. A kind appears only on a target whose registry and folders have it (the targets list the folders; `sulfur_cube_archetype` differs between versions, so the schema of each target decides). If the schema adapter cannot read the `concrete` node, the brief adds it to `@msm/schemas` with a test.
- **D2 Resource pack kinds.** `minecraft:post_effect` and `minecraft:waypoint_style` as schema-form kinds; `minecraft:shader` for shader program JSON; raw `.vsh`, `.fsh` and `.glsl` files go through project assets under a new allowed folder `shaders` (no schema; `export.language-unchecked` info as for other text without a checker).
- **D3 Left out, stated:** `slot_source`, `gpu_warnlist`, `regional_compliancies` (no pack folder or game-internal). The 26.4 `block_sound_set` belongs to [ADR 0105](0105-block-sounds-set-types-and-vanilla-block-pairs.md).
- **D4 Four data-only Creator flows.** "Banner pattern" (the pattern, its banner and shield pictures, the item that applies it in the loom and its item tag), "Armour trim" (the trim pattern, the template item, its smithing and copy recipes, the trim layer pictures and the atlas entry), "Glider" (an item with the `glider` component, its equipment asset and wing pictures, a repair item), "Pot pattern" (the decorated pot pattern, the sherd item, its face picture and the `decorated_pot_sherds` tag). Pictures are drawn by the art generator ([ADR 0092](0092-minecraft-style-art.md)); all four work in plain vanilla packs.

## Consequences

- Every data and resource pack folder vanilla reads has a kind or a stated reason for not having one.
- Four more flows; the asar grows by their recipes and templates (checked by `tools/check-size`).
- Raw shader files are unchecked text: a mistake shows only in game (guide note).

## Amendment (2026-11-22, after B508)

`minecraft:wolf_sound_variant` is left out of D1 again, as ADR 0064 decided: the vendored vanilla-mcdoc's `WolfSounds` and `OptionalWolfSounds` still have no `step_sound`, while the game refuses a wolf sound variant without it (B508's vanilla server run), so no file MSM writes can pass both. It returns with a vanilla-mcdoc sync that adds the field. D1 has seven generic kinds; with D2's three resource pack kinds the kinds count goes from 104 to 114.

## Findings at close (B523, 2026-11-22)

Recorded at the close of vanilla parity 3 batch 1 (B523) from the code on the session branch at 4ede504 and the plan's notes: B504 (636a5b6), B507 (5149004), B508 (f969a88), the wolf sound variant (dd46455, 374c94e), B516 (6f544a0), B517 (9646bad), B522 (a517f0c) and the merge findings (3cfb60e, 4ede504). No spike question belonged to this ADR.

- **D1 as built** (B504, amendment). Seven generic data kinds in `@msm/plugin-datapack` `kinds/generic.ts` (generic data kinds 35 in all): `minecraft:decorated_pot_pattern`, `block_transformer` (a top-level list of 1 to 200 transforms over `minecraft:rule_based` and `minecraft:simple` providers), `test_environment`, `test_instance`, `sulfur_cube_archetype` (12 archetypes on 26.3, 13 on 26.4 with `cold`; `hit_sound` and `push_sound` required on 26.3 only), `context_int_provider` and `context_float_provider`, each with default data valid on both targets and a template (data pack templates 73). All seven registries exist on both targets, so every kind is offered on both. The two context providers are reloadable registries, not world data folders. `DataFolderKey` gained seven keys ("Since 1.19.0"; `wolf_sound_variant` already had one). The schema adapter read the `concrete` node with no change to `@msm/schemas`. **`wolf_sound_variant` is out again** (the amendment): no file passes both the vendored mcdoc and the game.
- **D2 as built** (B504, B522, merge findings). `minecraft:post_effect`, `minecraft:waypoint_style` and `minecraft:shader` in `@msm/plugin-resourcepack` with templates "Spectator view effect", "Shader program" and "Waypoint style" (resource pack templates 20); the folders are constants in the kinds, not `ResourceFolderKey` entries (adding resource keys is not additive in 1.x). `shaders` joined `EXPORTED_ASSET_FOLDERS`: JSON there is checked as `resource:shader`, `.vsh`, `.fsh` and `.glsl` carry `language: 'glsl'` and an export reports one `export.language-unchecked` info. The Import assets dialog offers **Shaders (shaders, .vsh, .fsh and .glsl)** with an optional subfolder and the file picker says "Import shaders". Kinds 104 to 114 with D1 and D2, and 115 with ADR 0105's `msm:vanilla_block_rules`. Sidebar headings: Pot patterns, Block transformers, Test environments, Test instances, Sulfur cube kinds, Whole-number providers, Decimal-number providers, Screen effects, Waypoint styles, Shader programs.
- **D3** holds: `slot_source`, `gpu_warnlist` and `regional_compliancies` have no kind; `block_sound_set` is lowered by ADR 0105.
- **Vanilla pack safety** (B508, B517; ADR 0066). A vanilla 26.3 server loads all 352 library data packs, the new folders included; a vanilla server probe on 26.3 and 26.4 showed that a bad `block_transformer`, `sulfur_cube_archetype`, `test_environment` or `test_instance` file stops the world, so these four are `FATAL_DATA_FOLDERS` (`packages/exporters/src/vanilla-packs/mod-only.ts`); the context providers are not.
- **D4 as built** (B508). Creator flows `banner-pattern`, `armour-trim`, `glider` and `pot-pattern` (Creator flows 48 to 52, starters 60 to 64, examples of every new kind) with art recipes `pattern_sheet`, `pottery_sherd`, `glider`, `banner_pattern`, `shield_pattern`, `trim_layer_1`, `trim_layer_2`, `glider_wings` and `pot_pattern` (`art/recipes/patterns.ts`, recipes 80 to 89). Each flow's item is a vanilla item with components, because a vanilla pack cannot add items, so any plain item of the same type also works where a recipe names it. Very easy: the Home tile "Make a painting" is now "Make a painting or pattern"; "Make an item" offers Glider and "Make armour" Armour trim. `dataPackComponents` gained `provides_pottery_pattern` (B515). An AI-drawn trim layer has no palette file and does not recolour. All four work in plain vanilla packs.
- **Clean room** (B508). The worker read the PNG header sizes (no pixels) of seven vanilla textures and a few vanilla JSON files (atlases, `equipment/elytra.json`, `post_effect/invert.json`, an item tag) from the client jar to confirm layouts; nothing was copied or bundled. ADR 0092 D12 forbids measuring vanilla textures, so later briefs take sizes from the vendored data or the ADRs.
- **Open follow-ups.** `wolf_sound_variant` returns with a vanilla-mcdoc sync that adds `step_sound`; in-game checks of the trim recolouring with the flow's palette key (stored lightest first; verify at implementation), the loom taking the paper pattern item, the brick sherd's face on a pot and the glider's wings and gliding (Try it shows none of these).

## Status

Accepted with findings (2026-11-22, close B523; unreleased, awaiting the user's in-game checks). The user has not yet been shown the defaults and may still veto them. Vetoable defaults as built: shaders as unchecked raw files; the four flow names and their items as vanilla items with components; "Make a painting or pattern" on Home; `test_environment` and `test_instance` offered as kinds although only map makers use them; `wolf_sound_variant` left out until the vendored mcdoc has `step_sound`. Proposed at first (2026-11-22) with these defaults: shaders as unchecked raw files; the four flow names; `test_environment` and `test_instance` offered as kinds although only map makers use them.
