# ADR 0069: Block family flows

## Context

With block types ([ADR 0067](0067-block-types-and-states.md)) and plants ([ADR 0068](0068-crops-saplings-trees-and-leaves.md)) a project can make every member of a vanilla wood or stone set, but a set is fifteen or more elements, each with models, recipes, tags, loot and a name. Vanilla's wood set is log, wood, stripped log, stripped wood, planks, stairs, slab, fence, fence gate, door, trapdoor, button, pressure plate, leaves, sapling and a tree (plus signs, hanging signs, boats and shelves, which ADR 0067 D11 leaves out); a stone set is the block, stairs, slab, wall, and often a button, a pressure plate, a polished or brick variant and stonecutter recipes. Creator flows are parameterised starters with `creator` ([ADR 0043](0043-creator-guided-flows.md), [ADR 0040](0040-wizards-as-parameterised-starters.md)); the Gear set flow already builds a whole material from one colour with tinted placeholder textures, recipes, tags and names, and `meta.creator` lets the user reopen a set without losing hand edits.

## Decision

- **D1 Four Creator flows** in `@msm/plugin-library`, group `blocks` (names default, vetoable):
  - **"Wood set"**: name, colour (bark and planks) and leaf colour or an image per texture, which members (default all of: log, wood, stripped log, stripped wood, planks, stairs, slab, fence, fence gate, door, trapdoor, button, pressure plate, leaves, sapling), set type and fence gate wood type (default `wood` and `oak`), leaf tint (default none with a pre-coloured texture, so the set looks right without the client hook; `foliage` offered), tree shape (straight, fancy, forking, cherry-like, dark oak 2x2: vanilla trunk and foliage placer pairs), "Grows in the world" (biomes, chance: a placed feature and an `msm:biome_addition`). Output: one `msm:block` per member with the ADR 0067 and 0068 types, the `minecraft:worldgen/feature` tree, `msm:strippable` from log to stripped log and wood to stripped wood, `msm:flammable` with vanilla's numbers, the project tags `<ns>:<name>_logs` (block and item; members log, wood and stripped forms) joined into `minecraft:logs` and `minecraft:logs_that_burn`, `minecraft:planks`, the vanilla recipes (planks from the logs tag, wood from four logs, stairs, slab, fence, gate, door, trapdoor, button, plate; `group` per vanilla), loot presets (`self`, `leaves` with the sapling), compost for leaves and sapling ([ADR 0060](0060-adding-to-vanilla-content.md)), names and the `msm:mod` element.
  - **"Stone set"**: name, colour or images, members (default block, stairs, slab, wall; optional button, pressure plate, polished block with its stairs, slab and wall, bricks, pillar), tool tier (default stone pickaxe, `requires_tool`), crafting and stonecutting recipes, `stone` set type for button and plate.
  - **"Crop"**: name, produce (a new food item with nutrition, or "plant the produce", carrot-like), stages (default 4 textures for 8 ages, as potatoes) or images per stage, seeds name, compost chances, "Villagers plant it", "Wild plants in the world" (optional: a `random_patch` feature of the crop at its maximum age through `msm:biome_addition`). Output: the `crop` block with `item.id` for the seeds, the produce item, the crop loot preset, tags, names.
  - **"Tree"** (for a tree without the building blocks, or with vanilla logs): log and leaves (new or vanilla), sapling, tree shape, "Grows in the world".
- **D2 Textures.** Tinted placeholder PNGs from one colour per member through `src/assets/png.ts` (new patterns: bark, log end, planks, door top and bottom, trapdoor, leaves, sapling, crop stages, seeds, produce), or an `image` parameter per texture ([ADR 0048](0048-pictures-screenshots-and-skins.md)); never vanilla textures. Generated block models come from the elements' `textures` fields (ADR 0067 D7), so a user who repaints a texture changes the whole family.
- **D3 Reopen.** Every element carries `meta.creator` (flow, set, values); the reopen rule of ADR 0043 applies unchanged, and members the user switches off in a later run are removed only when untouched.
- **D4 Templates and examples.** `@msm/plugin-blocks-items` adds one template per new type (17: Log or pillar, Facing block, Observer-like block, Slab, Stairs, Wall, Fence, Fence gate, Door, Trapdoor, Button, Pressure plate, Weighted pressure plate, Pane, Crop, Sapling, Leaves) using vanilla textures by id and vanilla trees; the worldgen plugin adds "Tree for a sapling". The library adds examples: a wood set, a stone set, a crop, a tree, a rotatable machine-like block and an iron-door-like door (all mirrored in `examples/`). The "Simple block" flow gains "Turns to face the player" (`horizontal`) and "Placed like a log" (`pillar`).
- **D5 App.** The Block Studio gains a Type picker (changing type keeps shared fields and drops the old type's fields in one undoable change), a Textures section per type with slot names in words, the type's fields (set type, wood type, base block, press time, weighted maximum, crop stages with a stage slider in the preview, sapling tree link to the feature, leaf tint), and previews of the generated models through the existing in-memory bundle preview (`preview/bundle-source.ts`). The feature form gains the Tree section of ADR 0068 D5. The Creator previews the whole set as a row of block models and the recipes as crafting grids (existing preview tabs).
- **D6 AI helper.** The system prompt and the kinds summary describe `type`, the per-type fields and the four flows; `add_starter` drives them as any flow.
- **D7 Vanilla pack safety.** Every member is mod-only; the vanilla data pack of a family project keeps only what names nothing mod-only (usually nothing but optional tag entries), with the `export.mod-only-reference` warnings of [ADR 0066](0066-vanilla-pack-safety.md). The CI library server check covers the new starters and examples automatically.
- **D8 Plugin API.** No new library type: flows use the existing parameter types (`string`, `colour`, `set`, `choice`, `boolean`, `number`, `image`). The new target facts are ADR 0067 D9 (plugin API 1.10.0).

## Consequences

- A whole wood or stone set is one Create in the Creator and one undo step; each member stays editable in the Block Studio.
- The asar budget (audit L15) grows by the flows, templates and examples; the briefs measure it with `tools/check-size`.
- The guide gains one page for block types, families and plants.

## Status

Proposed (2026-11-14). Defaults the user may veto: the flow names, the wood set's default members and leaf tint, the default tree shape, "Villagers plant it" on by default.
