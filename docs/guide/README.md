# MCSuperMods user guide

How to use MCSuperMods to make resource packs, data packs and Fabric mods with new blocks, items and animated mobs, including structures and custom biomes, for Minecraft Java Edition, without writing JSON or code; and, when you want to, with TypeScript scripts, as a Java project or with the help of an AI assistant.

| Guide | What it covers |
|---|---|
| [Your first mod](first-mod.md) | Start here if you are new: a ruby tools and armour mod from the Creator's Gear set in seven steps, tested in Minecraft with Test in Minecraft and exported as a Fabric mod jar; the same steps as the in-app **Welcome** |
| [Getting started](getting-started.md) | Install, first launch and Settings → Game locations, a first mod from the Custom ore starter wizard, forms and Studios, preview, problems, saving, exporting the Fabric mod jar and trying it in Minecraft, a data pack from the Functions starter, the command palette and keyboard shortcuts |
| [Structures](structures.md) | Importing a structure (`.nbt`, `.schem`), the Structure Studio, jigsaw blocks in the game, template pools and connections, making a structure generate (structure set, biome tag, existing and new worlds), exporting structures as `.nbt` and `.schem` |
| [Worldgen](worldgen.md) | The worldgen starters, how a custom biome reaches a world (world preset and World Type), the Biome Studio, configured and placed features, steps and the feature order rule, the climate map, the in-game check |
| [Blocks and items](blocks-and-items.md) | Creating blocks and items from templates, the Block Studio and Item Studio, events and the actions (including `run_script`, `apply_effect`, Hurt and Heal), armour and the equipment element, custom tool materials, weapons (spears, maces, bows, crossbows, shields), consumables and totems, the triggers (on hit, on use on a block, while held, while worn, on break, on place, on random tick, on entity inside) and their limits, fuel and compost, vanilla components, drops, display names, exporting the Fabric mod jar, the separate runtime for modpacks, installing into a Fabric game, Test in Minecraft, troubleshooting with the `[msm_runtime]` log line |
| [Block types, families and plants](block-types-and-plants.md) | Logs, slabs, stairs, walls, fences, gates, doors, trapdoors, buttons, pressure plates and panes, and crops, saplings and leaves: the Creator's Wood set, Stone set, Crop and Tree flows, the Block Studio's Type, Textures and Models sections, set types and wood types, burning and stripping, the Tree Studio, what the vanilla packs leave out and the limits |

| [Potions and brewing](potions.md) | Potions for the brewing stand from the Creator's Potion flow, the Effect Studio's Make a potion or the potion templates: the Potion Studio, effects, the brewing ingredient and base, longer and stronger versions and their ids, splash and lingering potions and tipped arrows, the brewing chain, names and colour, why vanilla packs leave potions out, limits, the in-game check, troubleshooting |

| [Entities and models](entities-and-models.md) | Importing a Blockbench model (`.bbmodel`, `.geo.json`, `.animation.json`), the Entity Studio, goals in plain words, natural spawning (biome tags and ids, weight), spawn eggs, events and `play_animation`, the On tick and On spawn triggers, the animated preview and its limits, the Fabric mod jar with GeckoLib or without it (nested by default, the one-off download, the separate option, the built-in renderer), the in-game check, troubleshooting |
| [Mob behaviours](mob-behaviours.md) | Pets, farm animals, mounts, flying and water mobs, shooters and bosses: the Creator's Pet, Farm animal, Mount, Flying mob, Water mob and Boss flows, the Entity Studio's Kind of mob, Movement, Ranged attack, Taming, Breeding, Riding, Variants and Boss bar sections, the animations for states, tame before breeding, choosing the renderer (GeckoLib, built-in, automatic), mobs on 26.4, the limits (ridden mobs, the built-in renderer, brain mobs, spawn caps, boss music, restarts), the in-game check, troubleshooting |
| [Scripting](scripting.md) | What scripts can do, the Script Studio and its TypeScript editor, the `msm` API and its fifteen events, inventory and equipment, player state, titles and boss bars, typed damage, raycasts and teleports between dimensions, `run_script` from the Events editor, the typings in `.msm/`, how scripts are transpiled to ES5, saved data in `entity.data` and `msm.storage` and its limits, scripts on the triggers, limits (no Java, the 2 second budget, server side only) and what is not possible yet, the in-game check, troubleshooting with the `[msm_runtime]` script lines |
