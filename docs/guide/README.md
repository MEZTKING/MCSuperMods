# MCSuperMods user guide

How to use MCSuperMods to make resource packs and data packs for Minecraft Java Edition, without writing JSON or code.

| Guide | What it covers |
|---|---|
| [Getting started](getting-started.md) | Install, first launch and Settings → Game locations, a first project from the Custom ore starter, forms, preview, problems, saving, installing into a launcher instance, trying it in Minecraft, a data pack from the Functions starter, the command palette and keyboard shortcuts |
| [Templates, starters and examples](templates-and-examples.md) | All 66 element templates by category, the 8 project starters, the 34 examples and the Examples gallery, copying versus opening an example, replacing placeholder textures and the music disc sound |

More help:

- [Using Prism Launcher or the CurseForge app](../../README.md#using-prism-launcher-or-the-curseforge-app): where instances are found and how to choose the install target.
- [Known limitations](../../README.md#known-limitations).
- [`examples/`](../../examples/README.md): the examples as ordinary projects you can open with **File → Open Project…**.

The guide describes the current release. The design behind the app is in [DESIGN.md](../DESIGN.md); what comes next is in the [roadmap](../ROADMAP.md).
