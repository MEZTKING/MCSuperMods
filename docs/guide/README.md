# MCSuperMods user guide

How to use MCSuperMods to make resource packs, data packs and Fabric mods with new blocks, items and animated mobs, including structures and custom biomes, for Minecraft Java Edition, without writing JSON or code; and, when you want to, with TypeScript scripts, as a Java project or with the help of an AI assistant.

| Guide | What it covers |
|---|---|
| [Your first mod](first-mod.md) | Start here if you are new: a ruby tools and armour mod from the Creator's Gear set in seven steps, tested in Minecraft with Test in Minecraft and exported as a Fabric mod jar; the same steps as the in-app **Welcome** |
| [Getting started](getting-started.md) | Install, first launch and Settings → Game locations, a first mod from the Custom ore starter wizard, forms and Studios, preview, problems, saving, exporting the Fabric mod jar and trying it in Minecraft, a data pack from the Functions starter, the command palette and keyboard shortcuts |
| [Structures](structures.md) | Importing a structure (`.nbt`, `.schem`), the Structure Studio, jigsaw blocks in the game, template pools and connections, making a structure generate (structure set, biome tag, existing and new worlds), exporting structures as `.nbt` and `.schem` |
| [Worldgen](worldgen.md) | The worldgen starters, how a custom biome reaches a world (world preset and World Type), the Biome Studio, configured and placed features, steps and the feature order rule, the climate map, the in-game check |
| [Blocks and items](blocks-and-items.md) | Creating blocks and items from templates, the Block Studio and Item Studio, events and the actions (including `run_script` and `apply_effect`), armour and the equipment element, custom tool materials, weapons (spears, maces, bows, crossbows, shields), consumables and totems, vanilla components, drops, display names, exporting the Fabric mod jar, the separate runtime for modpacks, installing into a Fabric game, Test in Minecraft, troubleshooting with the `[msm_runtime]` log line |
| [The Creator](creator.md) | Making a Gear set, a weapon, a consumable, a totem, an enchantment, a painting, a music disc, a block, a mob or a scripted item from a few questions: the flows and their fields, the live preview tabs, picking a picture, Create and Undo, Edit in Creator and the kept-edits rule, replacing placeholders, the AI helper and the in-game check |
| [Entities and models](entities-and-models.md) | Importing a Blockbench model (`.bbmodel`, `.geo.json`, `.animation.json`), the Entity Studio, goals in plain words, natural spawning (biome tags and ids, weight), spawn eggs, events and `play_animation`, the animated preview and its limits, the Fabric mod jar with GeckoLib (nested by default, the one-off download, the separate option), the in-game check, troubleshooting |
| [Scripting](scripting.md) | What scripts can do, the Script Studio and its TypeScript editor, the `msm` API and its nine events, `run_script` from the Events editor, the typings in `.msm/`, how scripts are transpiled to ES5, limits (no Java, the 2 second budget, server side only, no saved data yet), the in-game check, troubleshooting with the `[msm_runtime]` script lines |
| [Eject to a Java project](eject.md) | When to eject, Export Java project and its dialog, what the generated Fabric Gradle project contains, building it with JDK 25, what is not included (scripts), one-way, GeckoLib and licences |
| [The AI helper](ai-helper.md) | The optional assistant with your own Anthropic API key: getting a key, Settings → AI helper, what is sent and when, Chat mode, Explain and Ask AI, Build mode with its plan, reviewing and applying proposed changes, run limits, usage and cost, troubleshooting |
| [Minecraft versions](targets.md) | What a target is, the 26.3 release and the 26.4 snapshot, choosing the version of a new project, the status bar, Upgrade project target and reading its report, what differs per target (pack formats, file names, the runtime jar, GeckoLib and mobs, the Java project export), what happens when 26.4 is released |
| [Plugins](plugins.md) | What plugins can and cannot add, the plugins folder, installing one, Settings → Plugins and its states, trust and the sandbox, the sample Greetings plugin, making your own with `tools/new-plugin --external`, the manifest, API versions, troubleshooting codes |
| [Templates, starters and examples](templates-and-examples.md) | All 125 element templates by category (including structures, worldgen, blocks and items, armour and weapons, entities, models and animations, scripts), the 24 project starters (and which are Creator flows), the 71 examples and the Examples gallery, copying versus opening an example, why new blocks, items and mobs need the Fabric mod jar, replacing placeholder textures and the music disc sound |
