## Decisions (ADR drafts)

- [ADR 0035](adr/0035-plugin-sandbox-and-capability-manifest.md): third-party plugins run **one Web Worker per plugin in the renderer**, started from a `blob:` of the app's bootstrap plus the plugin bundle (no string evaluation; CSP gains `worker-src 'self' blob:` and states `connect-src 'self'`, `script-src 'self'`); manifest `msm-plugin.json` (`manifestVersion`, `id`, `name`, `version`, `apiVersion`, `main`, `schemas`, `capabilities`); a message-passing proxy that builds an ordinary `Plugin` whose functions resolve through the worker; deadlines per call and `plugin.*` problem codes; `editors`, `commands` and `targets` unsupported for external plugins in 1.0; threat model; sandboxed `srcdoc` iframe as the fallback. Resolves DESIGN Open Question 5.
- [ADR 0036](adr/0036-plugin-api-1.0-and-compatibility-policy.md): **plugin API 1.0.0**: the semver policy (1.x additive, 2.0 for anything breaking, `@deprecated` for one minor); `MaybePromise` on the five synchronous contribution functions and `lowerProjectAsync` in core; `TargetFacts` (data) versus `Target` (hooks) with `channel: 'release' | 'snapshot'`; `TemplateContext.target`, `BundleContext.target` and `supports?(target)` on templates, starters and examples; `ProjectStarter.parameters` and `BundleContext.values`; `MigrationChange.data`/`kind`; a `tsup` build and `pnpm pack` tarball attached to releases (npm publishing is a user decision).
- [ADR 0037](adr/0037-second-target-mc-26.4-and-target-upgrade.md): the second target is **`mc-26.4`**, pinned to `26.4-snapshot-7` now and re-pinned to the release when it lands (reserve B163); facts; no GeckoLib on 26.4 (entities export reports `export.no-geckolib-target`); `migrateFrom` driven by a removed-id table that a test ties to the diff of the vendored registries, plus known renames; the **Upgrade project target** command and dialog; `defaultTargetId` is the newest `release` target; DESIGN §9's support policy reworded. 26.2 rejected because its data formats differ in every worldgen and loot kind.
- [ADR 0038](adr/0038-per-version-runtime-builds.md): **per-version runtime builds** from one Gradle build: `-Pmc=<version>` reads `engine-mod/versions/<mc>.properties`, version-specific code in `src/mc/<mc>/java` overlays behind seams, jars named `msm_runtime-<version>+mc<mc>.jar`, the app stages and resolves one jar per target, a CI matrix over the versions, parity through the same property.
- [ADR 0039](adr/0039-documentation-site.md): **VitePress 2.0.0-alpha.21** (pinned; Vite 8 shared with the catalog; 1.6.4 as the fallback) in the workspace package `docs/site/` with `srcDir ../guide`, dead-link checking on, absolute GitHub URLs for repository files, deployed to GitHub Pages by `docs.yml` without secrets (the user switches Pages to "GitHub Actions" once).
- [ADR 0040](adr/0040-wizards-as-parameterised-starters.md): **wizards are starters with parameters**, rendered by the host as a multi-step New project dialog; the Custom ore and Custom mob starters gain parameters whose defaults reproduce today's output; the new Custom sword starter.

Fallbacks recorded for completeness: if B150 finds that a `blob:` worker cannot be constrained, B154 builds the sandboxed `srcdoc` iframe host with the same protocol (ADR 0035 D6). If B151 finds that Loom 1.19.3 refuses the snapshot, `loom_version` moves into `versions/<mc>.properties` and 26.4 uses `1.20.0-alpha.4` (and the 26.4 target's `fabric.loom` says so). If the VitePress 2 alpha does not build the guide, B158 pins 1.6.4. If 26.4 is released before B162, B162 performs the re-pin of reserve B163 itself.

- Sample plugin: folder `fixtures/sample-plugin/`, package `@msm/sample-plugin` (private, workspace), plugin id `sample.greetings`, kind `sample:greeting` (folder `greeting`, schema `::sample::greeting::Greeting`), template `sample-greeting`, example `sample-greeting-example`, validator `sample.empty-message`, bundle `dist/main.js`, symbols `dist/symbols.json`, manifest `dist/msm-plugin.json` (the `dist/` folder is what a user copies into `~/.msm/plugins/greetings/`).
